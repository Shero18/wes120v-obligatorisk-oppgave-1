 # WES120V-prosjekt
Dette prosjektet er laget som en del av WES120V.
## Om prosjektet

Prosjektet er et enkelt Vite-prosjekt som brukes i den obligatoriske oppgaven.

## Installasjon

Node.js og pnpm må være installert.

Installer avhengighetene med:

pnpm install

Start utviklingsserveren med:

pnpm dev

Nettsiden åpnes på adressen som Vite viser i terminalen.
